# Review affected answers

Open **Tools → Review affected answers**, or use the review notice above an affected answer. The queue lists ordinary questions once in tree preorder. Cross-branch dependencies can point across that order; this is a navigation order, not a claim that mixed tree/dependency graphs have a causal topological order. Structural directions retain their separate review control.

Each question shows its exact saved answer and state. Select a retained cause to see the current upstream question/answer, the recorded pre-change map revision and fingerprint, and current tree/explicit/mixed relationships. Dependency edits record whether a link was added or removed and both endpoints. A removed source or absent current path does not erase an outstanding historical cause.

The fingerprint identifies the saved map before the upstream change. It is not a claim of correctness, an external source citation, or a reconstruction of the original answer's creation context. Old answer text is not embedded in cause records. Local History may retain the prior snapshot, but a revision number alone is insufficient to match versions across collaborators. Legacy flags and causes older than the newest 32 records have an explicit earlier/legacy remainder rather than invented details.

- **Reaffirm for selected cause** previews keeping the answer and state while acknowledging only that cause against the current saved map. Other causes and the earlier remainder stay outstanding. Reaffirming the earlier remainder does not acknowledge separately retained causes. The question leaves the queue only after no causes remain.
- **Revise in editor** returns to the connected answer editor and retains any private draft. A normal save explicitly previews acknowledgment of all current causes for this answer, even if its text is unchanged. Changed answers still flag downstream reasoning through the normal consequence workflow.
- **Clear saved answer** first persists the selected private draft, then explicitly previews an empty answer in the Unanswered state and acknowledgment of all its causes. Failed draft persistence blocks the operation; editing during confirmation requires a fresh preview. Private drafts stay separate and recoverable; a differing draft requires the existing recovery choice. Downstream answers are preserved and flagged through normal consequences.

Reaffirming does not refresh research or verify evidence. Saved research remains distinguishable as stale; start research explicitly from the question's Research tab. Current upstream answers can themselves still need review, which the queue discloses. Review never starts generation or research automatically.

After confirmation, the queue stays modal until the save response is applied or the request times out. This prevents new editor input from racing the saved-base change; previews remain cancellable before confirmation. Page suspension closes the queue, and the persisted private draft remains recoverable.

The queue uses a read-only captured map and requires explicit refresh after saved sources change. The consequence token binds the operation, selected cause, entire saved map and captured work; another cause/source change, late helper result, expired token or journey switch invalidates it. The final write guard runs under the existing writer lock after history preparation. Failed precommit saves retain the prior map. Each successful acknowledgment, revision or clear uses ordinary private History; undo restores the prior causes and answers. Private editor content is never part of a reaffirm/clear request.

Adding/removing a dependency marks the dependent question and its reachable downstream reasoning. Answers remain intact. Retained research is conservatively stale because saved research lacks a complete context dependency set. The current provenance limit is 32 causes plus an earlier flag per node. Optional dependency cause fields require Explorer 0.1.84 or newer; earlier strict readers refuse those records rather than silently discard the extra fields. Existing answer/branch causes and boolean-only review flags still load. Native/shared JSON retain this metadata; reduced exports retain their existing exclusions.

Verification covers one-cause acknowledgments, multiple/legacy causes, strict validation and shared round trips, dependency removal, stale previews, private drafts, history and failed writes, deep tree order and UI cancel/refresh/revise/clear. Native narrow-pane, modal focus, screen-reader and keyboard checks remain pending owner verification. No browser or desktop automation was used.
