# Research prior art for Explorer

**Recommendation:** improve and evaluate Explorer's explicitly loaded research skill before adopting a framework. Borrow bounded inquiry, counter-evidence checks, and claim-to-source records. Keep the installed Copilot SDK, current permissions, and decision-shaped output. None of the four candidates establishes better concise options, tradeoffs, recommendations, or follow-up dialogue in Explorer.

This supports [issue #88](https://github.com/AndrewGodlewsky/Copilot-Explore/issues/88). Inspection date: **2026-11-18**. Only first-party repository/API reads were performed. No candidate was installed or executed; no candidate model calls, provider keys, or desktop/browser automation were used. Repository instructions were treated as source material. Quality, latency, tool-call counts, and cost in Explorer remain **unmeasured**.

## Open Deep Research: useful stopping rules, substantial orchestration

The Python application requires LangGraph, LangChain/provider clients, Tavily and MCP dependencies. It cannot be imported into Explorer's dependency-free JavaScript extension. Its [configuration](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/src/open_deep_research/configuration.py#L38-L120) separates clarification, supervisor iterations, concurrent researchers, and per-researcher tool iterations. Defaults are five concurrent units, six supervisor iterations, and ten researcher tool iterations. Those are orchestration limits, not a single request's cost ceiling. [Dependency manifest](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/pyproject.toml#L9-L47).

Search choices are Tavily, native OpenAI search, native Anthropic search, or none. MCP uses a configured HTTP server and explicit tool-name selection. Crucially, `search_api=none` leaves configured MCP tools available; it is not an offline policy. Tavily results are deduplicated by URL, summarized, and returned with source URLs. These source strings and prompted citations are not Explorer's host-observed fetch receipts. [Tool assembly](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/src/open_deep_research/utils.py#L452-L597), [source processing](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/src/open_deep_research/utils.py#L44-L135).

The supervisor stops on completion, no tool calls, or its iteration check; researchers have a separate cap. Prompts encourage stopping when searches repeat information and retaining source links through compression. Adapt the **sufficiency check**: identify the unresolved fact that could change a recommendation before another lookup. Avoid importing the multi-agent/report pipeline merely to answer one decision. [Runtime stopping](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/src/open_deep_research/deep_researcher.py#L243-L260), [inquiry and compression prompts](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/src/open_deep_research/prompts.py#L138-L221).

Its [LangSmith runner](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/tests/run_evaluate.py#L1-L15) and [LLM evaluators](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/tests/evaluators.py#L1-L54) provide reusable evaluation dimensions. [README leaderboard results](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/README.md#L83-L120) concern long research reports and are author-reported, not validation of Explorer.

## GPT Researcher: inspect each source path separately

GPT Researcher is a large Python application, with configurable model, embedding, retriever, scraper, and MCP layers. Defaults include Tavily retrieval, provider LLMs, web research, and disabled optional source curation. The curator itself is an LLM ranking step. [Defaults](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/config/variables/default.py#L3-L48), [curator](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/skills/curator.py#L21-L107).

The ordinary research path fetches supplied `source_urls`; extra web search requires `complement_source_urls`, default false. However, the local-document path calls the shared planning flow, which performs an initial retriever search even when documents were supplied. “Local” therefore does not establish no new retrieval. [Constructor](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/agent.py#L55-L85), [source branches](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/skills/researcher.py#L169-L230), [planning search](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/skills/researcher.py#L387-L390).

Domain restrictions also depend on the adapter: [Tavily forwards `include_domains`](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/retrievers/tavily/tavily_search.py#L108-L135), while [MCP explicitly does not use `query_domains`](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/retrievers/mcp/retriever.py#L45-L66). Its URL-security module rejects unsafe schemes/internal addresses but documents a remaining DNS-rebinding window and a private-URL override. This is not evidence of end-to-end redirect confinement. [URL validation scope](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/utils/url_security.py#L1-L25).

Deep research recursively reduces depth, bounds concurrency, stops empty/failed branches, and accumulates learnings, citations, context, and source records. Its child researchers explicitly use web mode and propagate MCP configuration; they do not propagate the parent's supplied URLs or domain list in that constructor. Avoid treating the ordinary supplied-URL contract as the deep workflow's contract. [Recursion and child construction](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/gpt_researcher/skills/deep_research.py#L425-L579).

Borrow source-preserving follow-ups and failure stopping. Its [citation metric](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/evals/quality_eval/metrics.py#L68-L128) compares domains appearing in body and references; it does not prove claim support. [Report-quality tests, cost/latency logs, and claim grading](https://github.com/assafelovic/gpt-researcher/blob/ddd4db36208d9c8e49f3b2436efda97baecb5433/evals/README.md) are useful evaluation references, not measured gains here.

## STORM: perspectives and dialogue without importing article machinery

STORM separates model and retrieval modules in a Python/DSPy pipeline. Co-STORM adds human turns and a maintained knowledge structure. These are promising ideas for asking a follow-up that exposes a missing constraint. They require multiple model roles and additional dependencies, while Explorer already has an owned SDK helper. [Dependencies](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/requirements.txt), [human-turn handling](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/collaborative_storm/engine.py#L698-L745).

STORM defaults to three conversation turns, three additional perspectives, and three queries per turn. Conversations can end earlier on empty/completion responses; absent retrieval produces an explicit inability-to-answer response. [Bounds](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/storm_wiki/engine.py#L134-L164), [question loop and evidence handling](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/storm_wiki/modules/knowledge_curation.py#L60-L82), [empty retrieval](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/storm_wiki/modules/knowledge_curation.py#L204-L245).

Retrievers expose URLs, snippets, titles and exclusions, with provider-dependent filtering. You/Bing default source predicates accept every source. More subtly, persona generation directly requests model-suggested Wikipedia URLs outside the injected retriever. Replacing the retriever would not alone centralize network policy. [Provider defaults](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/rm.py#L13-L173), [persona fetches](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/storm_wiki/modules/persona_generator.py#L10-L97).

URL-indexed information and citation remapping preserve provenance through article assembly. Borrow that principle and preserve Explorer's distinction between observed retrieval and model interpretation. [Information table and references](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/knowledge_storm/storm_wiki/modules/storm_dataclass.py#L48-L200). FreshWiki evaluates Wikipedia-style articles; WildSeek contains research topics and user goals. Neither establishes compact decision quality. [Evaluation datasets](https://github.com/stanford-oval/storm/blob/fb951af7744dab086e34962e9bc6fe878e145f83/README.md#L294-L310).

## Firecrawl: adapt evidence discipline, not the workflow's scale

The deep-research skill targets formal analytical reports and explicitly excludes product picks and routine lookups. Its declared input requires `FIRECRAWL_API_KEY`; collection uses hosted Firecrawl search/scrape through CLI or equivalent tools. The accompanying core skill allows Firecrawl CLI shell commands. These are external service/tool assumptions, not capabilities granted by installing prompt text in Explorer. [Scope and required key](https://github.com/firecrawl/skills/blob/1d4b0728d0f448cafef2eb8370c907fde7cb6f42/skills/workflows/firecrawl-deep-research/SKILL.md#L1-L40), [core tool boundary](https://github.com/firecrawl/skills/blob/1d4b0728d0f448cafef2eb8370c907fde7cb6f42/skills/core/firecrawl/SKILL.md#L1-L18).

It asks for a runtime tier, then suggests 3–5 queries/5–10 scraped sources even at the quick tier; larger tiers increase collection. It avoids duplicate scraping, requests counterarguments, records rerun inputs, and asks for source quality and uncertainty. These are prompt instructions, not enforced quotas, cancellation, or permission checks. Adapt the counter-evidence question and reuse already-fetched material; do not transfer source-count targets into a narrow decision. [Collection plan](https://github.com/firecrawl/skills/blob/1d4b0728d0f448cafef2eb8370c907fde7cb6f42/skills/workflows/firecrawl-deep-research/SKILL.md#L45-L69), [evidence and output contract](https://github.com/firecrawl/skills/blob/1d4b0728d0f448cafef2eb8370c907fde7cb6f42/skills/workflows/firecrawl-deep-research/SKILL.md#L95-L144). No executable evaluation suite was found in the inspected skills tree; the workflow supplies a quality checklist.

## Proposed implementation choice and evaluation gap

Explorer's [packaged skill](../com.github.copilot/extensions/explorer/research/skills/explorer-research/SKILL.md) already asks for 2–4 feasible options, conditional recommendations, uncertainty, bounded attempts, and material claims linked to sources. Candidate ideas should tighten those behaviors before adding another orchestration layer.

| Option | Expected effort / cost | Decision-support tradeoff |
| --- | --- | --- |
| Adapt the packaged skill | Small prompt/fixture work; no new service | Best initial fit; gains remain unmeasured. |
| Add JavaScript orchestration | Moderate implementation/testing; potentially extra model turns | Consider only if fixtures or authorized live trials expose a specific failure the skill cannot address. |
| Adopt a framework or hosted workflow | High integration burden; new runtime/provider/service obligations | More retrieval breadth and orchestration, with no demonstrated benefit for Explorer's concise decisions. |

Evaluate six or more fixed cases covering technical/nontechnical choices, changing facts, conflicting evidence, sparse evidence, and clarification without retrieval. Score feasible options, material tradeoffs, conditional recommendation, citation support, honest gaps, and preservation of prior user answers. Record actual latency, tool attempts and usage separately from prompt/schema fixture results. A synthetic response can verify handling; it cannot establish research quality. Live comparisons need separate authorization.

**The owner's network-policy choice remains unresolved.** No providers, keys, ambient skills, or broader retrieval modes are authorized by this comparison. No-new-retrieval reasoning can still transmit inputs to a model provider. Keep current permissions; assess source-free reasoning, approved-URL retrieval, and opt-in search as separate policies in the decision record. Relevant expansion remains gated on query disclosure [#41](https://github.com/AndrewGodlewsky/Copilot-Explore/issues/41) and redirect/DNS boundaries [#42](https://github.com/AndrewGodlewsky/Copilot-Explore/issues/42).
